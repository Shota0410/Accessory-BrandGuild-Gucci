真贋チェックガイド

本物と偽物を見分けるための6つのポイント

⛔ 真贋判定は専門の鑑定士への依頼が確実です。以下はあくまで参考情報。偽物の販売は法律違反です。
📋 1. シリアルナンバー・刻印（タグ）
✓ 本物の特徴
  • タグは革製または高品質なレザーで均一な厚み
  • 数字は均等なフォントで深く・くっきり刻印または印字
  • 「Made in Italy」の文字が正確・鮮明
  • シリアル番号は通常6〜7桁（モデルにより異なる）
  • タグ上部のステッチが均一で整然としている
  • 「GUCCI」ロゴのU字の幅が均等
✗ 偽物の特徴
  • タグが紙製・薄い・柔らかすぎる
  • 数字が薄い・滲んでいる・フォントが不揃い
  • 「Made in Italy」の文字が小さすぎる・歪んでいる
  • 桁数が異常に多い・少ない・不規則
  • ステッチが粗い・不均一・色がズレている
  • フォントの間隔が詰まりすぎ・広すぎ
🔤 2. ロゴ（GUCCI文字・Gマーク）
✓ 本物の特徴
  • 「GUCCI」の文字は全体的にスラリとした縦長フォント
  • GのフックはCに対してほどよく入り込んでいる
  • 文字間の間隔が均等・バランスが整っている
  • ダブルGマーク（GG）は左右対称で重なりが均等
  • 金具のロゴは鋭利に彫刻されクッキリしている
  • 刻印は深すぎず・浅すぎず均一な深さ
✗ 偽物の特徴
  • 文字が太すぎる・細すぎる・プロポーションがおかしい
  • GのフックがCに食い込みすぎ・または届いていない
  • 文字間隔が不均等・一部が接触している
  • GGマークの左右で大きさが違う・重なり具合が不自然
  • 金具の刻印が浅い・滲んでいる・フォントが違う
  • 刻印が不均一・一部が潰れている
⚙️ 3. 金具（チェーン・留め具・パーツ）
✓ 本物の特徴
  • ずっしりとした重量感がある（軽すぎない）
  • ゴールド金具は深みのあるマットゴールド or シャイニーゴールド
  • チェーンの各リンクが均一なサイズで繋ぎ目が滑らか
  • 金具裏面にも「GUCCI」刻印がある場合が多い
  • 鍍金（めっき）が均一で剥がれがない
  • 留め具・クラスプの動きがスムーズ
✗ 偽物の特徴
  • 異様に軽い・プラスチック感がある
  • 金色が安っぽい・ギラギラしすぎる・黄色みが強すぎる
  • チェーンリンクの大きさが不揃い・繋ぎ目が荒い
  • 金具裏に刻印がない・刻印が曖昧
  • 鍍金の薄さが目立つ・端が剥がれ始めている
  • クラスプの動きが引っかかる・ガタつく
🏅 4. 素材・品位刻印
✓ 本物の特徴
  • シルバー素材には「925」（純度92.5%）の刻印がある
  • ゴールド素材には「750」（18K）または「585」（14K）の刻印がある
  • 刻印は非常に細かく鮮明で、ルーペで確認できる深さがある
  • 金属の質感が重厚・肌なじみが良く変色しにくい
  • レザー使用部分（バングル等）は上質で均一な革の厚み
✗ 偽物の特徴
  • 品位刻印（925・750等）がない・読み取れないほど浅い
  • メッキが薄く、着用数回で下地の色が透けてくる
  • 金属が異様に軽い・表面がツルツルすぎる・粗い
  • 着用後に肌が変色する（緑・黒など）ことがある
  • レザー部分が合成皮革・薄い・端処理が粗い
🧵 5. ステッチ（縫い目）
✓ 本物の特徴
  • 縫い目が非常に細かく均一（1cmあたり10針前後）
  • 糸の色が素材と調和している（ベージュ・クリーム系が多い）
  • 縫い始めと終わりが丁寧に処理されている
  • 縫い目がまっすぐで端から均等な距離を保っている
  • レザーパーツ使用アイテムは力がかかる接合部も均一に縫製されている
✗ 偽物の特徴
  • 縫い目が粗い・大きい・不均一
  • 糸の色が明らかにおかしい（白・黒の粗い糸など）
  • 縫い始め・終わりに糸の飛び出しや処理不良がある
  • 縫い目が曲がっている・端との距離が不均一
  • ほつれやすい素材の糸を使用している
📦 6. 付属品（箱・保存袋・シリアルカード）
✓ 本物の特徴
  • ボックスは厚みのある硬質な紙・蓋に「GUCCI」刻印入りリボン
  • 保存袋はGGロゴ入りの厚手ダスティバッグ（ベージュ〜茶系）
  • タグの紙質が高品質・ロゴフォントが正確
  • シリアルカードは本体内タグと番号が一致する
  • 保証書・購入レシートがあれば日付・購入店も確認できる
  • 箱内のクッション紙がGGロゴプリント入り
✗ 偽物の特徴
  • ボックスが薄い・軽い・ロゴフォントがおかしい
  • 保存袋の生地が薄い・ロゴ印字が滲んでいる・色が違う
  • タグの紙質が安い・文字に印刷ズレ・フォント不一致
  • シリアルカードの番号が本体タグと一致しない
  • 箱・袋だけ本物で中身は偽物というケースも存在する
  • クッション紙にロゴがない・印刷が荒い
